# Tmux Terminals

一键恢复 Remote-SSH 断开后的终端工作区。

## 解决什么问题

用 VS Code Remote-SSH 时，连接一断，所有集成终端标签连同里面正在
跑的进程一起消失。重连后要手工重建每个终端、重新 `cd` 到各个工程
目录、重新敲一遍启动命令。

这个扩展在侧边栏维护一张终端清单。点一下，终端就回来了；如果远端
的 tmux 会话还活着，连**正在跑的进程和滚动历史**也一起接回来。

## 三个概念

- **条目**：一条记录，含 名称 / 远程目录 / 预设命令。名称只用于显示，
  随时可改；它**不是** tmux 会话名 —— 会话名由条目 id 派生，形如
  `tmuxterm-<id>`，所以改条目名称不会影响已建立的会话。
- **存活**：远端存在该条目对应的 tmux 会话。
- **接回**：附到已存活的会话上，进程和历史都还在。

## profile：直连 / 中转

每个条目带一个 profile，决定用哪个 claude 入口启动、从哪读模型清单：

| profile | 启动命令 | 模型清单来源 |
|---|---|---|
| `ccr`（本地中转，默认） | `claude --dangerously-skip-permissions` | `~/.claude/settings.json` |
| `direct`（官方直连） | `claude-direct --dangerously-skip-permissions` | `/etc/claude/direct.json` |

清单条目的徽标颜色表示 profile：🔵 蓝 = `ccr`，🟠 橙 = `direct`。
旧版（v1）清单迁移时，命令里含 `claude-direct` 的条目映射为 `direct`，
其余映射为 `ccr`。

## 安装

需要在**已连接到远端**的 VS Code 窗口里安装，扩展才会装到远端。

```bash
npx @vscode/vsce package
```

然后在远端窗口的扩展面板里选择「从 VSIX 安装」。

> 本扩展声明了 `extensionKind: workspace`，必须运行在远端才能调用
> 远端的 tmux。装在本地是无效的。

## 使用

| 操作 | 效果 |
|---|---|
| 标题栏 `+` | 新建条目（依次输入 名称 → 目录 → 命令，命令留空结束） |
| 点击条目 | 🟢 接回原进程；⚪ 新建会话并执行预设命令 |
| 标题栏 ⟳ | 恢复所有标记了「参与全部恢复」的条目 |
| 标题栏 ↻ | 只重查存活状态，不开终端 |
| 右键条目 | 编辑 / 复制 / 切换自动恢复 / 删除条目 / 杀掉远端会话 |

## 排序与批量操作

- **拖拽排序**：在「终端清单」里直接拖动条目即可重排。落点语义是「插到
  目标行之前」，拖到列表末尾 = 放到最后。排序只改本地清单顺序，**绝不
  触发任何 tmux 操作**，也不影响已建立的会话。
- **批量操作**：在「批量操作」面板里点击条目切换选中（实心勾 = 已选，
  空心圈 = 未选）。标题栏三个按钮把选中条目统一「设为中转 / 设为直连 /
  批量设置模型」。
- **短路径消歧**：目录以最短且可区分的形式显示 —— 从 basename 起，与
  他人重名就往上多带一层父目录，直到唯一；到根仍冲突则显示完整路径。

## 重要：预设命令只在「新建会话」时执行

会话还活着时，点击是**接回**，预设命令**不会**执行。

这是刻意的：如果往一个正在运行的会话里发命令，那行命令会作为键盘
输入进入你正在跑的进程（比如一个 claude、一个编译、一个 REPL），
后果不可预料。

想重新跑一遍预设命令，先右键「杀掉远端 tmux 会话」，再点击条目。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `tmuxTerminals.pollInterval` | `10000` | 存活状态轮询间隔（ms），`0` 关闭 |
| `tmuxTerminals.tmuxPath` | `tmux` | tmux 可执行文件路径 |
| `tmuxTerminals.storagePath` | `""` | 清单文件路径。留空用扩展存储目录，**重装扩展会清空** |

## 已知副作用：运行中切模型会改全局默认

- **未运行**的会话：切模型只改条目配置，下次打开时经 `--model` 启动参数
  带出，**不污染**全局默认。
- **运行中**的会话：切模型会发送 `/model <目标>` 立即生效（重启会丢对话，
  命令行 `--model` 也盖不过 resumed 会话，故必须用 `/model`）。这会**顺带
  改写** `~/.claude/settings.json` 里的全局默认模型。这是「立即生效」的
  代价，扩展如实照做、不试图规避 —— 若不想动全局默认，请在会话空闲时切
  或事后手动改回。

## 已知限制

- 条目按远端机器隔离（扩展在每台远端各存一份清单）。
- 远端没装 tmux 时仍能开终端并 `cd`，但没有接回能力。
- 远端机器重启过则所有 tmux 会话消失，所有条目会显示为 ⚪。
